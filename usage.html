Sand Player の使い方

Sand Player のトップ ／ English

Sand Player は、2 本の動画や画像を左右に並べ、その間に「差分」と「半透明の重ね合わせ」を表示して、違いを見つけるための比較用プレイヤーです。 画像の赤い枠と番号は、本文の番号に対応しています。

1. 動画を読み込む

  • ウィンドウの左半分（L）にドロップすると L、右半分（R）にドロップすると R に入ります
  • 何本でもまとめてドロップでき、それぞれのプレイリストに順に並びます。フォルダーをドロップすると、サブフォルダーの中も読み込みます
  • エクスプローラーで MP4・MOV・MKV・WebM を Sand Player で開くと、L に入ります
  • L と R の両方に動画がそろうと、自動で再生が始まります

対応している形式

種類形式
動画MP4、MOV、MKV、WebM（H.264、H.265/HEVC、VP8、VP9、AV1）
画像PNG、JPEG、GIF、WebP、BMP、AVIF

ProRes・DNxHD などの編集用コーデック、AVI・MTS・WMV・FLV・MXF、TIFF 画像には対応していません。再生できない動画は、その枠に「この動画は再生できません」と表示されます。H.265 の再生には、H.265 のハードウェアデコードに対応した GPU が必要です。

2. 3 つの表示モード

差分

L と R の違いを表示します。同じところは黒く、違うところだけが明るく表示されるので、2 本の動画の違いをすぐに見つけられます。

半透明

L の上に R を半透明で重ねて表示します（1）。R の濃さは、真ん中の下のスライダー（2）で変えられます（起動時は 50%）。

差分と半透明の両方

表示モードは、歯車メニューの「表示モード」で切り替えます。

  • 再生中も、L と R で同じ時刻のフレームどうしを比べます。同じ動画を並べれば、差分は真っ黒のままです
  • 長さが違うときは、短い方が最後のフレームで止まり、比較を続けます

3. 再生する（再生バー）

11歯車設定

← / → キーかマウスホイールで 1 フレームずつ、Shift を押しながらで 1/3 秒、Alt を押しながらで 1 秒ずつ動かせます。

シークバーの印とマーカー

  • シークバーの印（現在位置・A・B）にマウスを寄せると、印のすぐ上に「マーカー」が出て、その位置の秒とフレーム番号を表示します
  • マーカーをつまんでも、印を動かせます。動かしている間は、マーカーが出たままです
  • Shift を押しながら動かすと、0 フレーム目から数えて一定間隔の位置（10 フレームなら 0・10・20…フレーム目）に吸着します。間隔は、歯車メニューの「Shift + ドラッグの間隔」で、フレームか秒で決めます
  • ← / → キーやマウスホイールでコマ送りしている間と、そのあと 2 秒ほど、現在位置のマーカーが出ます

L と R のフレームレートが違うときは、画面の上に「フレームレートが異なります」と表示されます。その場合、左右の同期にわずかな誤差が生じます。

  • PC の性能や同時に再生する本数によって、本来のフレームレートで表示できないときは、画面の上に「再生が重く、本来のフレームレートで表示できていません」と注意が出ます（本来の 9 割を下回る状態が 3 秒続いたとき。回復すると消えます）。表示モードを「差分」か「半透明」の片方にするか、ウィンドウを小さくすると軽くなります

4. プレイリストを使う

  • 開く：画面の左端・右端にマウスを持っていくと開き、離れると閉じます。L キーか「Playlist」ボタンで、開いたままにできます
  • 切り替える：W / S キーで L の前後の動画、↑ / ↓ キーで R の前後の動画、PageUp / PageDown で両方を切り替えます。項目をクリックしても切り替わります。切り替えると、L と R とも頭から（A マーカーを置いていれば A から）再生します
  • 並べ替える：項目をドラッグします。反対側のプレイリストへドラッグすると、L と R の間で移動できます
  • 途中に足す：ファイルをプレイリストの項目の間にドロップすると、その位置に入ります
  • 複数を選ぶ（1）：Ctrl + クリックで 1 つずつ、Shift + クリックで範囲で選べます。選んだ項目は、まとめてドラッグできます。Esc で選択を解除します
  • 外す（2）：項目を下の「ここにドラッグしてリストから削除」に落とすか、選んで Delete キーを押します

5. キャプションを表示する

C キーか CC ボタンで、次の 4 つを切り替えます。

表示内容
CC（なし）表示しない
CC₁（詳細）ファイル名、解像度、フレームレート、コーデック、長さ、総フレーム数、現在の時間とフレーム番号
CC₂（名前のみ）ファイル名を画面の中央に大きく表示
CC₃（名前とフレーム番号）ファイル名と現在のフレーム番号を、端に小さく 1 行で表示
  • フレーム番号は、歯車メニューの「開始フレーム」の値から数えます（初期値は 0。会社に合わせて 1 や 1001 などにできます）
  • 位置は、キャプションをドラッグするか、Ctrl + 矢印キー、歯車メニューの「キャプションの位置」で四隅に動かせます
  • 大きさは、歯車メニューの「キャプションの大きさ」で変えられます

6. 右クリックメニュー・1 本だけ大きく見る

メニューのいちばん上に「左ビューの設定」「右ビューの設定」と出るので、どちらの設定か分かります。メニューを出している間は、プレイリストは隠れます。

項目働き
単体表示その動画だけを大きく表示（ダブルクリックでも同じ。もう一度で戻る）
この動画のサウンドを流すその動画の音だけを流す。最初は消音です
タイムシフトその側の再生タイミングをずらす（次の「7. タイムシフト」）
ディレクトリをエクスプローラーで開くファイルのあるフォルダーを開く
フルパスをコピー／ファイル名をコピーファイルの場所や名前をコピー
プレイリストをクリアその側のプレイリストを空にする

7. タイムシフト（再生タイミングをずらす）

L と R の再生を始めるタイミングを、それぞれずらせます。頭の位置が違う 2 本や、編集で前後した素材を、同じ場面どうしで比べるときに使います。L か R を右クリックして、「タイムシフト」に入力します。

番号項目内容
1秒ずらす量を秒で入力。＋で後ろ（遅れて始まる）、−で前（早く始まる）
2フレームずらす量をフレームで入力。秒とフレームは、片方を入れるともう片方も自動で変わります（その動画のフレーム単位にそろいます）
3範囲ずらせる範囲。前は、その側の動画の最終フレームが 0 フレーム目に来るまで。後ろは、L・R のうち長い方の動画の尺まで
4タイムシフトをリセットこの側のずれを 0 に戻す
5左右両方のタイムシフトをリセットL・R 両方のずれを 0 に戻す
  • まだ始まっていない側（1）：後ろにずらした側は、始まるまで最初のフレームを暗くして止めておきます
  • ずらしている側（2・3）：枠の上に「⇄ +48 f」のように、ずらしている量を表示します。これを押すと、L・R の両方にタイムシフトの窓が開き、入力欄のほかにスライダーでも調整できます（範囲は前・後ろにずらせる最大まで。白い縦線がずらしていない 0 の位置。Shift を押しながら動かすと、0 から一定間隔の位置に吸着）
  • 本来の 0 フレーム目（4）：タイムシフト中は、シークバーにずらしていない動画の 0 フレーム目を青い線で示します。前にずらすと、シークバーは 0 より前（-0:01 など）から始まります
  • 差分・半透明は、ずらした分を考えて、同じ時刻どうしのフレームを比べます
  • タイムシフトは動画ごとではなく、L・R それぞれに付きます。プレイリストで別の動画に切り替えても、その側のずれは残ります
  • 動画を切り替えてずらせる範囲が変わり、今のずれが範囲を超えたときは、「タイムシフトの最大値が更新されたので自動調整します」と表示して、範囲内に収めます（例：100 フレーム前にずらしていた側を 3 秒の動画に切り替えると、3 秒分まで）
  • タイムシフトは、アプリを閉じると 0 に戻ります

8. HDR の動画について

HDR（HLG・PQ）の動画は、比較のため、HDR 本来の見た目ではなく、信号の値のまま（トーンマッピングをかけずに）表示します。そのため、L・R・差分・半透明のどこでも同じ色になります。iPhone で撮った縦向きの HDR 動画にも対応しています。

9. キャプチャーモードで注釈を書き込む

カメラボタンを押すと、L・R と比較の表示を並べた今の画面が静止画になり、その上に注釈を書き込めます。見つけた違いや修正の指示を、画像にしてすぐに渡したいときに使います。

3〜6矢印・直線・円・四角形図形を描く

8ペン自由に線を描く

12CC書き出す画像のキャプションを切り替え（なし → CC₁ 詳細 → CC₂ 名前のみ → CC₃ 名前とフレーム番号）。C キーでも切り替えられる

  • 書き込んだ注釈は保存されないので、閉じる前にクリップボードへのコピーか PNG 保存をしてください
